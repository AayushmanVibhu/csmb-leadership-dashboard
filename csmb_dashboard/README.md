# CSMB Leadership Dashboard Prototype

This is a fictional hiring-exercise prototype, not an actual CSMB system.

## Run on Windows
1. Unzip the folder.
2. Open PowerShell or the VS Code terminal inside `csmb_dashboard`.
3. Run `py -m pip install -r requirements.txt`.
4. Run `py -m streamlit run app.py`.
5. Browser opens at http://localhost:8501 (or use the local URL shown in terminal).
6. Select **All Companies**, expand the browser to full screen, and screenshot the dashboard for Canva Slide 5.

Data files are generated from the provided fictional exercise data. To regenerate them run `py make_data.py`.

**Important:** The dashboard tracks operational status and attention items, not verified business impact. Staff-only confidential hiring information is omitted. The May 2026 follow-up is flagged as *status unknown in the sample*, not asserted to be missed.
